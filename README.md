# Nitish Gaidhane — Product Leadership Portfolio

Source for the portfolio hosted at https://portfolio.nitishgaidhane.chatgpt.site.

## Local preview

Run `python -m http.server 8000 --directory dist`, then open http://localhost:8000.

This is a buildless HTML, CSS, and JavaScript website. No dependencies or API keys are required. Ask Nitish uses curated local answers, not an LLM. Website access is managed separately through Sites.
